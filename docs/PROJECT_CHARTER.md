# 프로젝트 목표와 평가 기준

버전: 1.5 · 작성일: 2026-09-22 · 개정: 2026-10-02 · 적용: 새 전향적 평가부터

## 1. 목표

같은 기간·같은 통화에서 배당과 비용을 반영한 자동매매 전용 계좌 전체 수익률이
S&P 500 총수익률을 지속적으로 초과하는 자동매매 시스템을 구축한다.
목표 초과수익은 연간 최소 **+0.01%포인트(1bp)**다.
단일 거래·하루·선별된 종목의 이익을 계좌 전체의 초과수익으로 표현하지 않는다.

**승률보다 비용 차감 후 계좌 전체 수익률·초과수익과 누적 순이익을 우선한다.**
손실 거래/손실일이 더 많더라도 총이익이 총손실과 비용을 초과하고 위험 한도를 지키면
낮은 승률만으로 탈락시키지 않는다. 높은 승률도 순손실을 정당화하지 않는다.
거래 승률·수익일 비율은 진단 지표이며 최소 승률/수익일 비율 게이트를 두지 않는다.
보고서는 순수익률·초과수익·순손익·최대낙폭을 먼저, 승률·평균이익/평균손실·profit factor를
보조로 표시한다. 순이익 금액은 투입 자금과 함께 보고하며 자금 규모로 수익률 비교를 왜곡하지 않는다.
필수 검증을 갖춘 소액 실거래에 빠르게 도달하도록 작업 범위를 집중한다.

현재 프로젝트와 검증 자산은 유지한다. 외부 도구는 측정 가능한 문제를 해결할 때
한 구성요소씩 도입한다. 기능 수나 AI의 설명 품질을 투자 성과로 대신하지 않는다.
이 문서는 개발·평가 정책이며 실제 주문·자동 승격을 승인하지 않는다.

## 2. 비교 기준 — 고정

| 항목 | 결정 |
| --- | --- |
| 공식 통화 | USD. KRW 환산은 동일 FX 시각·출처로 양쪽을 환산한 보조 결과 |
| 공식 벤치마크 | S&P 500 Total Return(배당 재투자 포함). 가격지수와 구별 |
| 실용 보조 벤치마크 | SPY 배당 재투자 buy-and-hold. 지수와 동일하다고 표기하지 않음 |
| 계좌 범위 | 현금·미실현 손익·배당·이자·부채·거래비용을 포함한 전용 계좌 순자산 |
| 수익률 | 외부 입출금을 제거한 시간가중수익률(TWR). 입출금 시 평가액으로 구간을 나눠 복리 연결 |
| 기간 | 동일 시작·종료 시각. 매 거래일 정규장 종료 시 평가; 조기폐장·DST 반영 |
| 연간 판정 | 평가 시작 전 고정한 12개월 구간과 이후 비중첩 12개월 구간. 달력연도·rolling 12개월은 보조 |
| 초과수익 | 100 × (계좌 TWR − 벤치마크 총수익률), 단위 %p |
| 연간 목표 충족 | 해당 고정 12개월 구간 초과수익 ≥ +0.01%p이며 데이터·위험 게이트 통과 |
| 지속성의 운영상 기준 | 연속 2개 비중첩 12개월 구간에서 각각 목표 충족. 미래 보장·통계적 확증과 구별 |
| 짧은 표본 | 12개월 미만은 누적수익을 보고. 연환산값으로 연간 목표 달성을 주장하지 않음 |

목표 충족과 통계적 불확실성은 별도 보고한다. 표본 수·변동성·drawdown을 병기하며,
신뢰구간·다중비교 방법은 검증 표본을 보기 전 개별 사전등록에 고정한다.
1bp보다 큰 가격·배당·비용 오차가 해결되지 않으면 목표 달성 판정은 유보한다.

S&P 총수익 데이터가 없으면 공식 비교는 `INCONCLUSIVE_BENCHMARK`로 남긴다.
SPY 결과만으로 S&P 총수익률 초과를 확정하지 않는다. split-adjusted 가격만으로
배당 재투자를 가정하지 않는다. 새 유료 공급자 가입은 이 문서의 범위가 아니다.

## 3. 비용·세금·현금

- 공식 운용 성과: 수수료·규제비용·환전비용·차입/대주비·금융비용 및 전용 운영비를 반영한다.
  체결 가격에 포함된 스프레드·슬리피지를 다시 중복 차감하지 않는다.
- API·서버 등 반복 운영비는 전용 사용분을 사전에 정한 배분법으로 비용 처리한다.
  개발에 쓴 개인 시간은 제외하고, 거래비용 후/운영비 후 결과를 각각 표시한다.
- 공식 비교는 개인별 소득·양도세 차감 전, 배당 원천징수 전 기준으로 통일한다.
  실제 현금흐름에는 원천징수를 기록하고 공식 성과에서는 별도 조정한다.
  세후 계좌 결과도 별도 보고하며, 세전 결과를 실수령 수익으로 부르지 않는다.
- 현금 대기일도 평가 기간에 포함한다. 현금 이자는 실제 지급 또는 검증된 적용률만 인정한다.
- 초기 전향적 shadow 비용은 왕복 0.34%p를 기준, 0.68%p를 stress로 사용한다.
  0.14%p는 과거 비교용 낙관 감도이며 실제 가능한 수수료라고 주장하지 않는다.
  v1.3부터 새 Paper 계약은 확인된 브로커 실제 비용에서 stress를 정하고, 값은 해당 계약 JSON이 정본이다
  (`premarket_freeze_long_intraday_v1`: [PREREG JSON](research/PREREG_PREMARKET_FREEZE_LONG_PAPER_V1.json)).
  기존 사전등록과 read-only 사후 방향성 장부의 0.68%p는 소급 변경하지 않는다.
  gross-edge 사전등록의 0.204%p 등 기존 개별 계약은 소급 변경하지 않는다.
- 실거래/모의 체결 승인 전에는 브로커의 실제 비용·주문단위·차입조건으로 별도 계약을 고정한다.
  고정 왕복 비용 모델은 계좌 전체에 매일 빼지 않고 거래한 명목금액에만 적용한다.

## 4. 평가와 승격 정책

1. **시작 전 계약 고정:** 진입·청산·손절·비중·보유기간·모의 체결·비용·판정 규칙을
   고정하고 구현 리뷰를 마친 뒤 첫 미래 거래일을 지정한다.
   watchlist만 있는 날은 모의 주문·체결 검증 완료일로 소급 인정하지 않는다.
2. **Shadow/Paper 통합 평가:** 같은 **10거래일** 동안 장전 판단 관찰과 모의 주문·체결·
   포지션·청산·비용·위험 한도 검증을 병행한다. 추가 60거래일 대기와 최소 30거래 조건은 폐지한다.
   모든 예정일·누락·NO_TRADE를 보존한다. 2026-09-21은 이미 본 사례이므로 제외한다.
   10거래일은 소액 실거래 검토 시점이며 연간 초과수익이나 지속성을 입증하는 기간은 아니다.
3. **통합 평가 조건:** 고정 버전의 10거래일 결과에서
   비용·운영비 후 누적수익 > 0, 동일 기간 SPY 총수익 대비 초과수익 > 0,
   stress 거래비용 후 누적손익 ≥ 0, 선택한 위험 한도 준수.
   주문/체결/잔고 미해결 불일치 0, 중복주문 0, 중단·복구·청산 검증을 요구한다.
   완료 모의 거래가 0건이면 실행 경로 미검증으로 판단한다. 고정 거래 수를 채우기 위한
   강제 매매는 하지 않는다. 거래 수·거래일 수·편중을 공개하며, 미검증 필수 경로가 있으면
   해당 원인과 필요한 추가 검증만 명시해 연장한다. 장애 경로는 별도 재현 테스트로 검증한다.
   이 수치는 프로젝트 운영 정책이며 수익성의 통계적 보증은 아니다.
4. **결정:** 모든 조건 충족 시 `ELIGIBLE_FOR_LIVE_REVIEW`만 부여한다.
   표본·데이터 부족은 `EXTEND_OBSERVATION`, 경제성 미충족은 `NO_PROMOTION`,
   위험/운영 위반은 `HALT_AND_REVIEW`. 실제 주문은 별도의 사용자 승인이 필요하다.
5. **변경:** 결과를 본 뒤 규칙을 바꾸면 새 버전과 새 검증 기간으로 평가한다.
   관측 후 완료 조건을 소급 완화하지 않는다.

기존 blind OOS·사전등록·미승인 전략 경계는 유지한다. 이 문서는 기존 OOS 개봉이나
과거 실패 결과의 재분류를 허용하지 않는다. 신규 숏은 LONG 성과로 승인하지 않고,
차입 가능성·차입비·배당 지급 의무와 별도의 Paper 결과를 요구한다.
인버스 ETF 매수는 롱 포지션이므로 신규 숏의 차입·배당 지급 요건은 적용하지 않는다. 다만 인버스 다리 결과는
따로 보고하며 LONG 성과로 승인하지 않는다.

## 5. 위험 정책

2026-09-22 사용자 선택: **일일 손실 1%, 고점 대비 손실 10%에서 중단**.

- 일일 손실: 직전 거래일 정규장 종료 순자산 대비, 외부 입출금을 제거한 현재
  순자산 손실률 ≥1%. 첫 운용일은 시작 직전 순자산을 기준으로 한다.
- 고점 대비 손실: 입출금 영향을 제거한 단위 NAV의 운용 시작 이후 고점 대비
  하락률 ≥10%. 일별 종가뿐 아니라 운용 중 평가값에서도 감시한다.
- 두 지표 모두 실현/미실현 손익과 발생 비용을 포함한다. 어느 한도든 도달하면
  신규 진입을 막고 미체결 진입 주문을 취소하며, 위험을 줄이는 청산 절차를 시작한다.
  통신 단절·갭·체결 지연으로 실제 손실은 한도를 넘을 수 있으며 한도는 보장 손절가가 아니다.
- 일일 한도: 당일 자동 재개 금지. 다음 거래일 잔고/체결 대조와 원인 점검을 통과하고
  사용자 재개 승인을 받은 후 재개한다. 고점 대비 한도: 자동 재개 금지,
  원인 리뷰와 사용자 재승인 필요. 재시작·입출금으로 고점 기록을 초기화하지 않는다.
- Paper도 같은 위험 정책을 사용한다. 한도 감시·취소·청산·재개 제어의 구현 검증은
  실제 계좌 운용 이전의 필수 조건이다.

초기 자금은 자동 결정하지 않으며, 계좌 연결 단계에서 사용자가 정한 금액을 승인서에 고정한다.
초기 운용은 차입 레버리지 없이 총 익스포저 ≤ 계좌 순자산 100%로 제한한다.
이 절의 익스포저는 보유 포지션의 가격 명목금액이며 레버리지 ETF 배수를 곱하지 않는다(2026-09-30 사용자 결정).
종목별 한도는 개별 전략 계약이 정한다. 소액 계좌에서는 고정 종목 비중이 성립하지 않을 수 있으므로
(정수 주식 기준; Paper 계약 v1.3부터는 소수점 수량), 계약은 `총 노출 × (손절폭 + stress 왕복비용) < 일일 손실 한도`를 만족하는 총 노출 상한으로
손실을 통제한다. v1.2까지의 종목별 ≤ 25%는 v1.3에서 이 규칙으로 대체했다.
초기 승인 전까지 LONG/SHORT 관찰은 허용하되 실제 포지션 권한을 뜻하지 않는다.

## 6. 변경 규율과 근거

- 목표·비교·비용·위험·승격 기준 변경은 버전·이유·효력 시작일·이미 본 데이터를 기록한다.
- 문서의 기준과 코드 구현 완료는 별개다. ROADMAP/PROJECT_STATUS에 구현 상태를 표시한다.
- 각 완료 단계는 코드/PR/테스트/결과 아티팩트 등 증거 링크가 있어야 한다.
- 총수익 정의: [S&P Index Mathematics](https://www.spglobal.com/spdji/en/methodology/article/index-mathematics-methodology/).
- 보조 벤치마크: [State Street SPY](https://www.ssga.com/us/en/intermediary/etfs/state-street-spdr-sp-500-etf-trust-spy).

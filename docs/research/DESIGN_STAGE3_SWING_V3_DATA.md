# 단계 3 스윙 v3 데이터 확장 설계 (2026-10-02)

목적: S&P 500 구간을 1928년부터로 늘려 큰 하락장 사례(1929, 1937, 1973~74, 1987 등)를 시험에 넣는다. 사용자 결정 2026-10-02.
이 문서는 지수 데이터 점검만 담는다. 어떤 규칙의 수익률도 계산하지 않았다.

## 출처

| 항목 | 출처 | 구간 |
| --- | --- | --- |
| S&P 500 가격(신호·가격 수익) | Yahoo `^GSPC` 일별 종가, `period1=-1325635200` | 1927-12-30~ (24,559행, 2026-10-02 조회) |
| 1988년 이전 배당 | Robert Shiller `ie_data.xls`(Yale) 월별 `P`, `D`(연환산 배당) | 1871-01~2023-06 |
| 1988년 이후 총수익 | Yahoo `^SP500TR` (v1·v2와 같음) | 1988-01-04~ |
| `rf` | Ken French 일별 RF (v1·v2와 같음) | 1926-07-01~ |

## 배당 추정식

1988-01-04 이전의 S&P 총수익 `r_u(t) = 가격 수익(t) + (D_m / P_m) / 252`. `m`은 t가 속한 달(Shiller 월 값). 이후는 `^SP500TR`.

점검(1988-01-05~2023-06-30, 8,943일, 추정식 vs `^SP500TR`):

| 지표 | 값 |
| --- | --- |
| 연환산 수익 | 추정 10.68%, 실제 10.74%, 차이 −0.06%p |
| 일별 상관 / 주간 상관 | 0.99960 / 0.99994 |
| 연도별 총수익 차이 | 최대 0.40%p, 평균 −0.06%p |
| 1928~1987 배당 결측 일수 | 0 |

## 사전등록에서 정할 것(사용자 확인 필요)

1. **VIX가 없는 구간:** VIX는 1990년부터다. 규칙 10(S&P)은 1928~1989에 계산할 수 없다. 선택지: 규칙 10 S&P는 1991년 이후 시작점만 평가 / 규칙 10 S&P 제외.
2. **시대 점검(4번):** 확장 구간에 맞는 시대 나누기. 예: 1929~1959, 1960~1993, 1994~2025-07-18 중 2개 이상.
3. **토요일 거래:** 1952년 이전 NYSE는 토요일에도 열렸지만 Yahoo 일별에는 토요일 행이 없다(토요일 움직임은 월요일 수익에 합쳐짐). 그대로 쓰고 한계로 적는다.
4. **새로운 증거의 범위:** 1928~1993의 S&P는 이 저장소에서 어떤 규칙 결과도 계산한 적이 없는 구간이다. 1994~2025는 v2에서 이미 봤다. 결과 보고에서 두 구간을 따로 보여준다.
5. **의존성:** `.xls`를 읽으려면 `xlrd`가 필요하다. 프로젝트 의존성에 추가하거나, 내려받을 때 CSV로 바꿔 저장한다.

# 사전등록 — SPY 첫 30분 → 마지막 30분 장중 모멘텀 v1

> 작성: 2026-08-10 · 이슈 #122 · **development-only**  
> 상태: **결과 미열람.** 이 문서는 구현·성과 계산 전에 규칙과 판정 기준을 고정한다.

## 1. 질문과 근거

Gao, Han, Li, Zhou의 *Market Intraday Momentum*은 전일 시장 종가부터 당일 첫 30분까지의 시장 수익률이
마지막 30분 수익률을 예측한다고 보고했다. 논문의 타이밍 규칙처럼 신호가 양수이면 마지막 30분에 시장을
매수하고, 음수이면 매도한 뒤 종가에 청산한다.

- 1차 근거: [Journal of Financial Economics 논문 페이지](https://www.sciencedirect.com/science/article/pii/S0304405X18301351)
- 보조 근거: [SSRN 원문 페이지](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2440866)

이 검증은 논문의 역사적 성과를 재주장하지 않는다. 현재 저장소의 고정 데이터와 훨씬 보수적인 비용 계약에서
같은 구조가 살아남는지만 묻는다.

## 2. 데이터와 구간

- 종목: **SPY 한 종목**.
- 장중 데이터: 고정 1분봉 스냅샷
  `p0_us30_orb_clean_1m_asof_20260721.bd9fc14.sqlite`.
- 전일 종가: `data/market_history.sqlite`의 SPY 수정 일봉. 반드시 **직전 NYSE 거래일**과 정확히 일치해야 한다.
- development 평가: **2023-05-18 ~ 2026-01-20**.
- blind OOS: **2026-01-21 ~ 2026-07-21**. 이번 작업에서 로드하거나 열람하지 않는다.
- 장중 4개 identity와 일봉 manifest identity 중 하나라도 다르면 실행을 중단한다.

## 3. 단 하나의 전략 규칙

각 NYSE 거래일에 완전한 REGULAR 1분봉 격자가 있을 때만 평가한다.

1. `first_half_hour_return = 09:59 ET 완료봉 종가 / 직전 거래일 일봉 종가 - 1`.
2. 값이 양수면 **LONG**, 음수면 **SHORT**, 정확히 0이면 거래하지 않는다.
3. 정규장 마감 30분 전 1분봉의 **시가**로 진입한다.
   - 정상장: 15:30 ET.
   - 조기폐장: 해당 마감 시각에서 30분을 뺀 시각.
4. 정규장 마지막 완료 1분봉의 **종가**로 청산한다.
5. 손절·익절·재진입·포지션 전환·overnight 보유는 없다.
6. 거래량·변동성·RSI·EMA·국면 필터를 추가하지 않는다.

## 4. 크기와 비용

- 초기자본: **$100,000**.
- 매일 고정 초기자본의 100% 이내에서 `floor(100000 / entry_price)`주. 레버리지·복리 없음.
- 왕복 비용: low **0.14%p**, official **0.34%p**, stress **0.68%p**.
- 비용은 `(진입금액 + 청산금액) × 왕복비율 / 2`로 차감한다.
- SHORT도 같은 비용을 적용한다. 30분 이하 SPY 공매도에 대한 별도 borrow 비용은 모델링하지 않는 한계가 있다.

## 5. 판정

63 거래일 블록을 평가창 끝에 정렬한 10개 fold로 안정성을 본다. 파라미터 적합은 없다.

| 게이트 | 고정 기준 |
|---|---|
| D1 | 거래 ≥ 300 |
| D2 | 거래 발생일 ≥ 200 |
| D3 | official 거래당 기대값 > 0 |
| D4 | official PF ≥ 1.2 |
| D5 | official MDD ≤ 10% |
| D6 | 양수 fold ≥ 7/10 |
| D7 | stress 누적 순손익 ≥ 0 |
| D9 | SPY 불완전 거래일 비율 ≤ 5%, 직전 일봉 누락 0, 신규 충돌 0, 중대 결함 0 |

- D9 실패: `INCONCLUSIVE_DATA`.
- D9가 통과했지만 D1~D7 중 하나라도 실패: `NO_SELECTION`.
- 전부 통과: `GO_CANDIDATE`. 이는 즉시 Paper/실거래 승인이 아니다.

## 6. 결과 보고 규율

- primary 한 개만 실행하고 sensitivity나 조건부 하위집합을 만들지 않는다.
- low/official/stress, LONG/SHORT, 10개 fold, 신호 부호 수, 품질 결함을 모두 공개한다.
- 결과가 불리해도 이번 실행에서 규칙·비용·게이트를 고치지 않는다.
- Paper·실거래·주문·위험·config를 변경하지 않는다.

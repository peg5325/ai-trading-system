## 0. 왜 이 검증인가 (아직 안 본 유일한 질문)

지금까지 검증한 것은 "점수/컴포넌트가 **개별 후보의** 미래 수익을 맞히는가"(H1/H2 — 전부 null)다.
그러나 종목이 3개뿐이라 스크리너는 **여럿 중 상위를 고르는 '선별'을 해본 적이 없다**(rank 항상 1).
12종목 유니버스에서는 매 시점 여러 후보가 경쟁하므로, **"점수 상위 N을 고르면 무작위보다 나은가"**를
처음으로 검증할 수 있다.

**예상**: H1(점수↔수익 상관≈0)을 고려하면 **null 가능성이 높다.** 그럼에도 이 "선별" 프레임은
직접 검증한 적이 없으므로, 경로 A를 정직하게 닫기 위해 **사전등록 하에 딱 한 번** 수행한다.

---

## 1. 가설 (H4)

> **매 결정 시점에 candidate_score 상위 N 종목을 선택하면, 무작위 N 선택 및 전체 동일가중 대비
> 비용반영 forward return이 유의하게(일-블록 기준) 높다.** = 스크리너의 랭킹에 선별 가치가 있다.

방향 대조: 상위 N > 하위 N 이 일관된 부호로 성립해야 한다.

## 2. 데이터 & 유니버스 (시점별 선택가능 종목)

- 소스: `datasets/h2b_candidates_final.jsonl` (12종목, 94거래일, 59,949 후보; score·forward return 보유).
- **시점별 후보 풀**: 각 `bar_ts_utc`에서 그 시점에 스크리너를 통과(score≥45)한 종목들의 집합.
- **교차종목 랭킹 재구성**: 데이터셋의 `rank`는 종목별 개별 스크리닝이라 항상 1 → **사용 금지.**
  대신 **같은 시점 후보들을 `candidate_score`로 정렬**해 교차종목 순위를 구성(점수는 종목 간 비교가능).

- (선택적 충실도) 라이브와 완전히 같으려면 유니버스 인지 추출기로 재생성 가능하나, 본 검증은

## 3. 평가 방법 (arms)

각 시점, 후보 수 ≥ N+1 인 경우에만 평가. N ∈ {1, 2, 3} (사전 고정, 추가 N 탐색 금지).

| arm | 정의 |
|---|---|
| **top_N** | 점수 상위 N — cutoff **동점은 tie-aware 분수 배분** (아래) |
| **bottom_N** | 점수 하위 N (방향 대조) — 동점 처리는 top_N 과 동일 규칙 |
| **random_N** | 무작위 N — **전수 조합 C(k, N) 열거로 정확값**(평균+분포). 전수 열거가 비현실적인 초대형 풀에서만 **seed 고정** MC 폴백 |
| **equal_all** | 그 시점 전체 후보 동일가중 — **random_N 전수 열거와 항등이므로 "항등 검산 라인"으로만 보고**(별도 게이트 아님, §6(c)·v1.3) |

- **동점(tie) 처리 (v1.2 확정)**: 경계(cutoff) 점수에 동점 종목이 여럿이면 임의 순서로 자르지 않고,
  **남은 슬롯을 동점 종목들에 균등 분수 배분**한다(예: 남은 슬롯 1개에 동점 3종목 → 각 1/3 가중).
  bottom_N 도 동일 규칙. 이로써 선택이 입력 순서·정렬 tie-break 에 의존하지 않는다.
- **순서 불변 테스트 (실행 단계 필수)**: 입력 행 순서/symbol 정렬 순서를 바꿔도 모든 arm 결과가
  동일함을 검증하는 테스트를 분석 스크립트에 포함한다(§7).

각 arm의 성과 = 선택된 후보들의 **비용반영 forward return** 평균(분수 배분 시 가중 평균).

## 4. 비용 반영

- 왕복 비용(config 모델) = **14bps**(fee 2bps + slippage 5bps, 편도 7bps × 2) — 라이브 config와 동일.
- 비용반영 수익 = `forward_return_pct − 0.14%p`. 모든 arm에 동일하게 빼므로 arm 간 **차이(초과분)에는
  상쇄되어 영향이 없다** — 절대 수준(0 대비)을 볼 때만 작동한다.
- **top−random 의 0.34%p 문턱은 "사전 고정 최소 효과크기"다 (v1.2 명확화)** — arm 간 차이에는 비용이
  이미 상쇄되어 있으므로 **비용을 다시 적용하는 것이 아니다.** 크기의 눈금만 증거장부의 실측 거래당 비용
  0.34%p(#003+#005+phase6 s001, "비용 0.34%p > 총이익 0.22%p" — `DECISION_MEMO_AB.md` §1)에서 빌려
  H3/H3-b 와 같은 잣대로 고정한다(§6(a)). config 이론값 0.14%p 는 문턱으로 쓰지 않고(선행 분석 전부보다
  낮은 잣대가 되므로) 감도 참고로만 병기한다.
- **결과 보고는 두 항목으로 분리한다 (v1.2 도입, v1.3 확정)**: ① **증분 랭킹 가치** = top_N − random_N
  (최소 효과크기 0.34%p 로 판정, §6(a)) ② **전략 경제성** = top_N 의 **OOS (forward − 0.34%p 실현비용)
  일-블록 평균 > 0**(§6(e)). config 이론값 **0.14%p 차감 결과는 RESULT 에 감도로 병기**한다(0.34/0.14
  양쪽). ①이 성립해도 ②가 실패하면 "랭킹에는 정보가 있으나 전략은 비용을 못 넘는다"로 기록한다 —
  두 질문을 섞지 않는다.
- 지평: **30m, 60m, EOD** (다일은 별개 실험; 본 검증은 intraday 선별력에 한정).

## 5. 통계 (사전 확정)

- **판정 단위 = 일-블록.** 각 날의 arm별 평균을 하나의 관측으로 → 일 단위 검정(관측단위 p 금지 — H3의 pseudo-replication 함정 재발 방지).
- top_N vs random_N, top_N vs bottom_N을 **일별 대응 Wilcoxon signed-rank**로 — 같은 날 두 arm
  평균의 차이가 대응 관측이다. (MWU 는 독립표본 검정이라 대응 비교에 쓰지 않는다.)
  **검정 상세 (v1.3 확정)**: **양측(two-sided)**, 0 차이(zero-difference) 일은 제거하고, 제거 후
  **유효일 < 6 인 셀은 유의 판정 불가**로 취급한다(양측 signed-rank 최소 p = 2/2ⁿ 이 n<6 에서
  0.05 를 넘는다 — 그 셀은 유의 요구 조건을 충족할 수 없다).
- **OOS/embargo (v1.2 확정, v1.3 정밀화)**: 고유 거래일 D 개를 시간순으로 **in-sample = 앞 ⌊0.70×D⌋ 일,
  OOS = 나머지 전부**로 분할(일 경계 — 같은 날이 양쪽에 걸치지 않음). embargo 는 **in-sample 쪽 경계
  마지막 1거래일을 제거**하는 방식으로 한다(OOS 쪽 제거 없음; 최장 지평 EOD ≤ 1거래일이라 누수 차단에
  충분). random CV 금지. holdout(OOS) 판정 기준은 **명목 p < 0.05 + 부호·효과크기 유지** — 상세는 §6(d).
- 효과크기를 **사전 고정 최소 효과크기 0.34%p** 와 대비(§4 — 비용 재적용 아님) — 유의성이 아니라
  크기로 실용성 판정.
- 다중검정: 판정 대상인 top_N vs random_N 검정 9개(N 3 × 지평 3), **α=0.05 Bonferroni 보정 →
  판정 임계 p < 0.05/9 ≈ 0.0056**. 명목 p 는 참고로 병기한다.

## 6. ★ 사전 판정 기준 (결과 보기 전 확정)

- **GO (스크리너 선별력 있음) — 셀 규칙 (v1.2 확정, v1.3 정밀화)**: 셀 = (N, 지평), 총 **9개**(N∈{1,2,3} × 지평 3).
  **9개 중 ≥1 셀이 아래 (a)(b)(d)(e)를 전부 충족**하면 GO — (c)는 v1.3 에서 게이트에서 제거(아래 사유).
  셀 단위 판정은 H3/H3-b 의 (정의×지평) 칸 판정과 같은 형식이다.
  - **(a) in-sample**: top_N − random_N 초과분이 **양(+)** 이고 **일-블록 검정 Bonferroni 통과**(p < 0.05/9, §5)
    이고 효과크기 ≥ **0.34%p**(사전 고정 최소 효과크기, §4),
  - **(b)** 같은 셀의 **in-sample 일-블록 평균 부호**로 판정: **일별 (top_N − bottom_N) 평균 > 0** (v1.3 확정),
  - **(c)** *(v1.3 게이트 제거 — 검산 라인으로 강등)*: 전수 조합 열거 하 random_N 기대값 ≡ 모집단 평균 ≡
    equal_all 이므로 top−random ≡ top−equal_all (in-sample·OOS 공통). (c)는 (a)와 **항등**이라 별도
    게이트가 아니며, equal_all 은 **random_N 항등 검산 라인**으로만 보고한다,
  - **(d)** 같은 셀이 **OOS 에서 재현**: 부호 동일 **그리고** 효과크기 ≥ 0.34%p **그리고** 명목 p < 0.05
    (일-블록 signed-rank, §5),
  - **(e)** 같은 셀에서 **top_N 의 OOS (forward − 0.34%p 실현비용) 일-블록 평균 > 0** (v1.3 — 차감 비용을
    config 이론값 0.14%p 에서 실현 비용으로 **강화**; 0.14%p 차감 결과는 RESULT 에 감도 병기.
    "전략 경제성" 축, §4),
  → 이 경우 경로 A에 **선별 기반의 남은 여지** 있음 → 후속 설계.

- **NULL (경로 A 종료)**: **어떤 셀도 (a)(b)(d)(e)를 전부 충족하지 못함** → **스크리너 선별력 미입증 → 경로 A 공식 종료.**
  결정메모 §5 의 A 완전 종료 2요건 중 **(b) 다개월 장기 horizon 은 H3-b 로 이미 확인**됐다
  (`h3b_longhorizon_validation.md`, verdict = no — 일-블록 검정 통과 실패). 따라서 본 검증이 null 이면
  (a) 선별력 null 이 충족되어 **(a)+(b) 모두 성립 → 경로 A 공식 종료**가 결정메모와 정합한다.

- **사전 중단**: N∈{1,2,3}·지평 3개의 **단일 패스**만. 추가 파라미터 탐색·재실행으로 GO를 찾지 않는다.

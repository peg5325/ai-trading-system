## 0. 왜 이 검증인가 (아직 안 본 유일한 질문)

지금까지 검증한 것은 "점수/컴포넌트가 **개별 후보의** 미래 수익을 맞히는가"(H1/H2 — 전부 null)다.
그러나 종목이 3개뿐이라 스크리너는 **여럿 중 상위를 고르는 '선별'을 해본 적이 없다**(rank 항상 1).
12종목 유니버스에서는 매 시점 여러 후보가 경쟁하므로, **"점수 상위 N을 고르면 무작위보다 나은가"**를
처음으로 검증할 수 있다.

**예상**: H1(점수↔수익 상관≈0)을 고려하면 **null 가능성이 높다.** 그럼에도 이 "선별" 프레임은
직접 검증한 적이 없으므로, 경로 A를 정직하게 닫기 위해 **사전등록 하에 딱 한 번** 수행한다.

---

## 1. 가설 (H4)

> **매 결정 시점에 candidate_score 상위 N 종목을 선택하면, 무작위 N 선택 및 전체 동일가중 대비
> 비용반영 forward return이 유의하게(일-블록 기준) 높다.** = 스크리너의 랭킹에 선별 가치가 있다.

방향 대조: 상위 N > 하위 N 이 일관된 부호로 성립해야 한다.

---

## 2. 데이터 & 유니버스 (시점별 선택가능 종목)

- 소스: `datasets/h2b_candidates_final.jsonl` (12종목, 94거래일, 59,949 후보; score·forward return 보유).
- **시점별 후보 풀**: 각 `bar_ts_utc`에서 그 시점에 스크리너를 통과(score≥45)한 종목들의 집합.
- **교차종목 랭킹 재구성**: 데이터셋의 `rank`는 종목별 개별 스크리닝이라 항상 1 → **사용 금지.**
  대신 **같은 시점 후보들을 `candidate_score`로 정렬**해 교차종목 순위를 구성(점수는 종목 간 비교가능).
- 세션: PRE/REGULAR/POST (OVERNIGHT 제외, 기존 모집단과 일치).
- (선택적 충실도) 라이브와 완전히 같으려면 유니버스 인지 추출기로 재생성 가능하나, 본 검증은
  기존 데이터의 점수 기반 재구성으로 충분하며 그 한계를 결과 문서에 명시한다.

## 3. 평가 방법 (arms)

각 시점, 후보 수 ≥ N+1 인 경우에만 평가. N ∈ {1, 2, 3} (사전 고정, 추가 N 탐색 금지).

| arm | 정의 |
|---|---|
| **top_N** | 점수 상위 N |
| **bottom_N** | 점수 하위 N (방향 대조) |
| **random_N** | 무작위 N (200회 추출 평균 + 분포) |
| **equal_all** | 그 시점 전체 후보 동일가중 |

각 arm의 성과 = 선택된 후보들의 **비용반영 forward return** 평균.

---

## 4. 비용 반영

- 왕복 비용(config 모델) = **14bps**(fee 2bps + slippage 5bps, 편도 7bps × 2) — 라이브 config와 동일.
- 비용반영 수익 = `forward_return_pct − 0.14%p`. 모든 arm에 동일하게 빼므로 arm 간 **차이(초과분)에는
  상쇄되어 영향이 없다** — 절대 수준(0 대비)을 볼 때만 작동한다.
- **실용성 문턱(§6.2)은 실현 비용 0.34%p/거래를 쓴다.** 근거: 증거장부의 실측(#003+#005+phase6 s001,
  "비용 0.34%p > 총이익 0.22%p" — `DECISION_MEMO_AB.md` §1)과 H3/H3-b 판정이 전부 이 값을 기준으로
  썼다. config 이론값 0.14%p 를 문턱으로 쓰면 선행 분석 전부보다 낮은 잣대가 되어 사전등록 취지에
  반하므로, 0.14%p 는 판정에 쓰지 않고 감도 참고로만 병기한다.
- 지평: **30m, 60m, EOD** (다일은 별개 실험; 본 검증은 intraday 선별력에 한정).

---

## 5. 통계 (사전 확정)

- **판정 단위 = 일-블록.** 각 날의 arm별 평균을 하나의 관측으로 → 일 단위 검정(관측단위 p 금지 — H3의 pseudo-replication 함정 재발 방지).
- top_N vs random_N, top_N vs bottom_N을 **일별 대응 Wilcoxon signed-rank**로 — 같은 날 두 arm
  평균의 차이가 대응 관측이다. (MWU 는 독립표본 검정이라 대응 비교에 쓰지 않는다.)
- **OOS/embargo**: 날짜 시간순 분할, embargo ≥ 지평. random CV 금지.
- 효과크기를 **실현 비용(0.34%p/거래)과 대비** — 유의성이 아니라 크기로 실용성 판정(§4).
- 다중검정: 판정 대상인 top_N vs random_N 검정 9개(N 3 × 지평 3), **α=0.05 Bonferroni 보정 →
  판정 임계 p < 0.05/9 ≈ 0.0056**. 명목 p 는 참고로 병기한다.

---

## 6. ★ 사전 판정 기준 (결과 보기 전 확정)

- **GO (스크리너 선별력 있음)**: 아래 **모두** 충족
  1. top_N 비용반영 수익이 random_N 대비 초과분이 **양(+)이고 일-블록 검정 Bonferroni 통과**(p < 0.05/9, §5),
  2. 초과분 크기가 **실현 거래당 비용(0.34%p) 이상** — 0.14%p(config 이론값)~0.34%p 구간이면
     "이론비용만 넘음"으로 기록하되 GO 아님,
  3. top_N > bottom_N 부호 일관,
  4. OOS에서 재현.
  → 이 경우 경로 A에 **선별 기반의 남은 여지** 있음 → 후속 설계.

- **NULL (경로 A 종료)**: 위 GO 조건을 **하나라도 충족 못 함** → **스크리너 선별력 미입증 → 경로 A 공식 종료.**
  결정메모 §5 의 A 완전 종료 2요건 중 **(b) 다개월 장기 horizon 은 H3-b 로 이미 확인**됐다
  (`h3b_longhorizon_validation.md`, verdict = no — 일-블록 검정 통과 실패). 따라서 본 검증이 null 이면
  (a) 선별력 null 이 충족되어 **(a)+(b) 모두 성립 → 경로 A 공식 종료**가 결정메모와 정합한다.

- **사전 중단**: N∈{1,2,3}·지평 3개의 **단일 패스**만. 추가 파라미터 탐색·재실행으로 GO를 찾지 않는다.

## 0. 한 문장

**지금의 "고정 3종목 · 롱온리 · 기술점수 · intraday(30분~EOD)" 틀은 검증 가능한 모든 지점에서 예측 엣지가 없음이 확인됐다. 이제 이 틀을 계속 다듬을지(A), 틀 자체를 바꿀지(B)를 정할 시점이다.**

## 2. 무엇이 성공이었나 (버리지 말 것)

전략은 엣지가 없지만, **연구 인프라는 성공**이다. 시스템은:
- 세션 격리·리스크 가드·청산·계측이 무오류로 반복 실행됨.
- **가짜 신호를 빠르게 죽이는 능력**을 갖춤 — s001 artifact, look-ahead 오염(15~147배), pseudo-replication(관측 p 1e-45 vs 일단위 1.0), 데이터 결측을 전부 잡아냄.

→ 이 "정직한 검증 기계"는 **어떤 전략을 하든 재사용할 자산**이다. B로 가더라도 이 위에서 검증한다.

## 3. 선택지

### 경로 A — 현 틀 유지, 재료/파라미터 개선
현 intraday 롱온리 틀을 두고, 새 재료(피처)를 계속 찾거나 SL/TP·종목을 조정.

- **장점**: 기존 시스템 재사용, 점진적, 파괴 적음.
- **단점**: 엣지가 **없다고 이미 광범위하게 확인됨.** 남은 A 카드(선별·다개월)는 약하거나 데이터가 필요. **"밑 빠진 독에 물 붓기" 위험 최고.**
- **A에서 그나마 남은 것**: ① 종목을 크게 늘려 **스크리너 선별력** 검증(새 질문), ② 다개월 데이터로 장기 horizon 재검증.

### 경로 B — 틀 자체를 바꾼다
문제의 근원(방향 엣지 부재 + 비용 초과)을 정면으로.

- **B-1 시간축 전환(스윙)**: intraday→며칠~몇 주 보유. **회전↓ → 비용↓**(아는 문제 직접 공략). 가장 자연스러운 첫 후보.
- **B-2 방식 전환**: 방향 예측을 버리고 **상대가치(페어/통계적 차익)**, 이벤트 기반 등. 방향 엣지가 필요 없는 접근.
- **B-3 롱온리 탈피**: 롱/현금(국면 회피) → 이후 롱/숏. 단 국면 신호가 약해(H3) 근거는 제한적.

- **장점**: 아는 문제를 정면으로. 근본적.
- **단점**: 상당 부분 재설계. 크고 되돌리기 어려움.

## 4. Claude 권고

**B로 전환하되, B-1(시간축)부터.** 근거:

1. A의 핵심 전제(재료 개선으로 엣지)가 **광범위하게 반증**됨. A를 계속하는 건 증거에 반함.
2. 유일하게 크기가 컸던 신호가 **다일 horizon**이었음(유의하진 않았으나 방향 지시). → 더 긴 보유가 가리키는 곳.
3. B-1은 **아는 문제(비용>수익)를 직접 완화** — 회전을 줄이면 비용 드래그가 준다. 방향 엣지 없이도 net을 개선할 여지.
4. 기존 백테스트 엔진·105일 데이터로 **라이브 없이 오프라인 검증 가능** — 값싸게 시작.

**A를 완전히 닫기 전 딱 하나 남은 값싼 확인**: 종목을 크게 늘려 스크리너 *선별력*을 오프라인으로 1회 검증(§1 미검증 (b)). 이것도 null이면 A는 완전히 닫힌다.

## 5. ★ 사전 중단 기준 (무한 튜닝 방지 — 지금 박아둘 것)

> 결정을 데이터에 맡기되, **무엇을 보면 멈출지 미리** 정한다. 사후에 정하면 원하는 답에 맞춰 움직이게 된다.

- **A 완전 종료 조건**: (a) 종목 확대 후 스크리너 선별력 오프라인 검증이 null + (b) 장기 horizon도 일-블록 검정 통과 실패 → **A 종료, B 확정.**
  > **교정 (2026-07-21, H4 결과 후)**: 원문의 "다개월 장기 horizon"은 과장이었다 — H3-b가 실제 검증한 최대 지평은 **5일**이다. (a)는 H4로 null 확인, (b)는 **≤5d 범위에서** null(H3-b) 확인. **다개월/스윙은 미검증이며 이는 경로 A가 아니라 경로 B의 영역**이다. 따라서 경로 A(현 intraday~5d 틀) 종료는 사전조건의 문자적 충족이 아니라 **H4 NULL 위에서의 전략(범위) 결정**으로 기록한다. 상세 `RESULT_screener_ranking_h4.md` §4 · `PREREG_screener_ranking_h4.md` ERRATUM E1.
- **B-1(스윙) 진행 조건**: 오프라인 스윕에서 **회전↓이 비용을 줄여 net이 유의하게(일-블록 기준) 개선**되면 → 라이브 B-실험 설계. 개선 없으면 B-1 폐기, B-2로.
- **전체 프로젝트 재검토 조건**: B-1·B-2 모두 오프라인에서 **비용 반영 후 net > 0 을 일-블록·OOS로 못 보이면** → "실자금 투입 없이 연구/학습 프로젝트로 재정의" 검토.
- **모든 판정 공통**: random CV 금지, 일-블록/OOS/embargo, look-ahead 철벽, 효과크기를 비용과 대비(유의성≠크기).

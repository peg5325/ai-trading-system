# 탐색용 Paper 데이트레이딩 규칙 v1.0 (TQQQ/SQQQ)

작성: 2026-10-04 · 근거: [Charter v2.3 §4.6](../PROJECT_CHARTER.md), [설계 리뷰](REVIEW_DAYTRADE_SITUATION_LAYER_20261004.md) §3, 사용자 결정(2026-10-04: 10/5 세션부터, TQQQ/SQQQ 한 쌍)
표시: `EXPLORATORY_PAPER`. 실제 주문 없음. 결과는 우위의 증거가 아니다. 규칙 변경은 다음 세션부터 새 버전(v1.1, …)으로만 한다.

## 1. 방식

장 마감 후 그날 1분봉(`data/market_history.sqlite`, 읽기 전용)으로 상황을 판정하고 규칙대로 가상 체결한다. 판정·체결은 **그 시각까지 완결된 봉만** 쓴다.
시각은 미국 동부시간(ET). 신호 지수 QQQ, 롱 = TQQQ 매수, 숏 = SQQQ 매수.

## 2. 입력

| 입력 | 계산 |
| --- | --- |
| 일봉 | QQQ 정규장(REGULAR) 1분봉을 날짜별로 묶은 시가·고가·저가·종가 |
| BULL/BEAR | 전일 QQQ 종가 > 50일 단순평균이면 BULL |
| ATR14 (%) | QQQ 일봉 14일 평균 진폭 ÷ 전일 종가 |
| 위험 모드 HIGH | 전일 VIX 종가 ≥ 30 또는 VIX9D/VIX > 1.1 (Cboe 일별 CSV). HIGH면 크기 절반 |
| 갭 | 09:25 이전 마지막 PRE 1분봉 종가 ÷ 전일 정규장 종가 − 1. PRE 봉이 없으면 09:30 시가 사용 |
| 개장 15분 | 09:30~09:44 봉. 범위 = (고가 − 저가) ÷ 전일 종가, RVOL = 거래량 합 ÷ 직전 20세션 같은 구간 평균 |
| VWAP | 09:30부터 누적, 각 종목 자기 VWAP |
| 이벤트 | `config/daytrade_events_v1.yaml`: FOMC 결정일, CPI·NFP·PCE 발표일, 조기폐장일(공식 출처 링크 포함) |
| 기록만(판단 안 씀) | 전일 GEX(SqueezeMetrics), 옵션 만기일 여부 |

## 3. 상황과 행동 (09:45 판정, 지표 발표일은 10:15)

| 상황 | 조건 | 진입 | 손절 | 청산 |
| --- | --- | --- | --- | --- |
| S0 | FOMC 결정일 또는 조기폐장일 | 없음 | | |
| S1 | (갭 ≥ +0.3% 또는 BULL·갭 ≥ 0) · 판정 직전 봉 종가 > 09:30 시가 · > VWAP · RVOL ≥ 1.2 · 범위 ≥ 0.4 × ATR14 | 판정 시각 봉 시가에 TQQQ | TQQQ 개장 구간 최저가. 진입가 대비 1.5%보다 멀면 **진입 안 함** | 10:30 이후 TQQQ 5분봉 종가 < TQQQ VWAP이면 다음 봉 시가, 아니면 15:55 봉 시가 |
| S2 | S1의 거울(갭 ≤ −0.3% 또는 BEAR·갭 ≤ 0 · 종가 < 시가 · < VWAP · RVOL ≥ 1.2 · 범위 조건 동일) | SQQQ | SQQQ 개장 구간 최저가, 1.5% 상한 동일 | SQQQ 기준 동일 |
| S3 | S1·S2 아님 · 갭 ≤ −1.0% · BULL · HIGH 아님 · 10:00에 09:55 5분봉 종가 > QQQ VWAP · 세션 저점이 09:50 전에 생기고 그 뒤 안 깨짐 | 10:00 봉 시가에 TQQQ | TQQQ 세션 저점 −0.2%, 1.5% 상한 | QQQ 고가 ≥ 전일 종가인 봉의 종가, 또는 11:00 이후 TQQQ 5분봉 종가 < VWAP이면 다음 봉 시가, 또는 15:55 |
| S4 | 위 어느 것도 아님 | 없음 | | |
| S5 | 14:44 QQQ 종가 ÷ 전일 종가 − 1 ≥ +2%면 TQQQ, ≤ −2%면 SQQQ | 14:45 봉 시가 | 진입가 −1.5% | 15:55 봉 시가 |

- 지표 발표일(CPI·NFP·PCE)은 S1·S2·S3 판정 시각을 10:15로 미루고 개장 구간을 09:30~10:14로 쓴다.
- 같은 봉에서 손절과 청산 조건이 겹치면 **손절이 먼저**다. 손절 체결가 = min(손절가, 그 봉 시가)(롱 상품 기준, 갭으로 건너뛴 경우 불리하게).

## 4. 크기·비용·한도

- 가상 계좌 USD 2,000에서 시작, 날마다 이어간다.
- 크기: 명목 = (계좌 × 0.5%) ÷ 손절폭, 상한 계좌 × 35%(HIGH면 절반). S5가 S1/S2와 같은 방향이면 합산 상한 50%. 소수점 수량 허용.
- 비용: 매수·매도 각 수수료 0.10%, 매도에 SEC fee 0.00206%, 슬리피지 편도 0.05%(체결가에 반영). 왕복 약 0.3%.
- 하루 손실이 계좌의 3%에 닿으면 그날 신규 진입 없음. 15:55에 전부 청산.

## 5. 산출물

- `reports/daytrade_paper/YYYY-MM-DD.json`(gitignore): 규칙 버전, 입력값, 상황 라벨과 이유, 체결, 손익, QQQ·TQQQ 시가→종가 비교, 데이터 품질. 한 번 쓰면 덮어쓰지 않는다.
- `reports/daytrade_paper/ledger.json`: 날짜별 누적.
- `docs/journal/YYYY-MM-DD.md`: AGENTS.md 일지 형식. 사실 부분은 자동 생성, 회고(잘한 점·잘못한 점·개선안·지난 개선안 점검)는 assistant가 쓴다.
- 1분봉이 불완전하면(정규장 390개 미만, 09:30·15:59 누락) `INCOMPLETE_DATA`로 기록하고 거래를 만들지 않는다.

## 6. 구현 해석 (v1.0, 2026-10-04 리뷰 반영)

위 규칙 문장과 임계값은 그대로다. 이 절은 v1.0 구현(`src/daytrade_paper/`, `scripts/run_daytrade_paper.py`)이
규칙 문장을 어떻게 읽는지 적은 것이고 규칙 변경이 아니다.

**봉 시각과 지표**

- 시각은 미국 동부(ET)다. `t`로 표시한 1분봉은 [t, t+1) 구간이다. "T에 판정"은 t < T인 봉만 보고, 체결은 T 봉 시가다.
- 갭: 09:25 전 마지막 PRE 1분봉 종가 ÷ 전일 정규장 종가 − 1. PRE 봉이 없으면 09:30 시가를 쓴다.
- 일봉(시가·고가·저가·종가)은 각 세션의 정규장 1분봉으로 만든다. SMA50 = 직전 50세션 종가 평균. BULL = 전일 종가 > SMA50.
- ATR14 = 직전 14세션 TR 평균 ÷ 전일 종가. TR = max(고가−저가, |고가−그 전날 종가|, |저가−그 전날 종가|).
- VWAP = 09:30부터 해당 봉까지 (고가+저가+종가)/3 × 거래량의 합 ÷ 거래량 합. 판정은 QQQ VWAP, 청산은 보유 종목(TQQQ/SQQQ) VWAP.
- RVOL = 당일 개장 구간 거래량 ÷ 직전 20세션의 같은 구간 거래량 평균. 범위 = 개장 구간 (최고가−최저가) ÷ 전일 종가.
- 5분봉은 09:30 기준 [s, s+5) 묶음이고 종가는 s+4 1분봉 종가다.

**판정과 청산 시각**

- S1·S2 청산 점검은 10:30 묶음(10:34 종가)부터 시작한다. 5분봉 종가 < VWAP이면 다음 봉, 즉 첫 가능 시점은 10:35 시가에 청산한다. S3는 11:00 묶음(11:04 종가)부터, 첫 청산은 11:05 시가다.
- 지표 발표일 S3는 10:15에 판정한다. 이때 "5분봉"은 10:10 묶음(10:14 종가), 저점 기준 시각은 판정 −10분인 10:05다.
- S3 "저점이 안 깨짐"은 엄격 비교다. 기준 시각 이후 저점 > 이전 저점이어야 하고 같으면 깨진 것으로 본다.
- S3 목표 청산은 QQQ 고가 ≥ 전일 종가가 된 봉의 TQQQ 종가다.
- 같은 봉에서는 손절이 먼저다. 대기 중인 청산(VWAP 신호)이나 15:55 강제 청산도 그 봉 시가가 손절가 이하이면 손절(STOP_GAP, 시가 체결)로 기록한다.
- 진입 봉 시가가 이미 손절가 이하이면(롱 상품) 진입하지 않는다. 이유: "진입 시가가 이미 손절가 아래".

**크기와 한도**

- 1.5% 손절폭 상한은 슬리피지를 반영한 체결가 기준으로 잰다: (체결가 − 손절가) ÷ 체결가. S5 손절가 = 체결가 × (1 − 1.5%).
- HIGH 절반은 35% 단독 상한을 적용한 뒤에 곱한다. S5가 같은 방향의 열린 주 포지션(S1·S2, 그리고 S3도 TQQQ이므로 포함)과 겹치면 합산 상한 50%(HIGH면 25%)에서 열린 명목을 뺀 만큼만 S5에 쓴다.
- S5가 열린 주 포지션과 반대 방향이면 허용한다(합산 상한 없음, 단독 상한만).
- S5 크기의 계좌 기준 = 시작 계좌 + 14:45까지 실현 손익.
- 일일 −3% 점검은 14:45(이후 유일한 신규 진입 시점)에 한다. 실현 손익 + 열린 포지션을 14:44 종가로 청산했다고 본 비용 차감 손익을 쓴다. S5가 발동하지 않아도 도달 여부를 리포트 `halt`에 기록하고, 마감 손익 기준 도달 여부(`reached_by_close`)도 함께 남긴다.
- 위험 모드: VIX ≥ 30이면 HIGH, 아니면 VIX9D/VIX > 1.1이면 HIGH. 둘 중 필요한 값이 없으면 UNKNOWN이고 HIGH로 취급한다(크기 절반, S3 불가).
- 외부 데이터(VIX·VIX9D·GEX)는 세션 날짜보다 앞선 마지막 값을 쓴다. 그 값이 7일보다 오래되면 없는 값으로 본다.

**데이터 품질과 달력**

- 거래일 달력: 평일에서 `config/daytrade_events_v1.yaml`의 `holidays`(NYSE 전일 휴장, 2026-11-26 추수감사절·2026-12-25 성탄절, https://www.nyse.com/markets/hours-calendars 에서 2026-10-04 확인)를 뺀 날이다. 달력 범위 밖은 평일만 안다.
- 조기폐장일은 정규장 210봉, 마지막 봉 12:59다(S0이라 거래는 없다).
- 과거 QQQ 세션이 50개 이상이어야 한다(SMA50; ATR14의 15개와 RVOL의 20개를 포함).
- DB의 마지막 과거 세션이 달력상 직전 NYSE 거래일이어야 한다. 그 세션은 QQQ·TQQQ·SQQQ 모두 마지막 봉(15:59, 조기폐장일이면 12:59)이 있어야 한다.
- RVOL 기준 20세션은 각각 개장 구간(09:30~09:44, 지표 발표일은 09:30~10:14) 1분봉이 빠짐없이 있어야 한다.
- 위 중 하나라도 어기면 `INCOMPLETE_DATA`(이유 포함)이고 거래를 만들지 않는다.

**실행기**

- 달력 범위(coverage) 밖 날짜는 실제 실행에서 거부한다(dry-run만 허용). 거래일이 아닌 날은 항상 거부한다.
- 원장 연속성: 원장에 기록이 있으면(첫 실행 이후) 달력상 직전 NYSE 거래일이 원장 마지막 날이어야 한다. 아니면 거부하고 빠진 날을 먼저 돌리게 한다.
- 실제 실행에서 데이터 품질이 실패하면 exit 3으로 거부하고 아무것도 쓰지 않는다(외부 CSV도 받지 않는다). `--accept-incomplete`를 주면 `INCOMPLETE_DATA`로 기록한다. dry-run은 그대로 기록한다.
- `--backfill-check`: 해당 날짜 봉을 DB에서 읽어 위 데이터 품질 검사만 하고 결과를 출력한다. 아무것도 쓰지 않고 외부 데이터도 받지 않으며 원장·write-once는 보지 않는다. 통과면 0, 실패면 3.
- `--out-root`: `reports/daytrade_paper/`와 `data/external/daytrade_paper/`의 루트(기본: 스크립트가 있는 저장소). 일지는 항상 스크립트 저장소의 `docs/journal/`에 쓴다. 루트가 `.claude/worktrees/` 안이면 경고한다.
- 쓰기 순서는 리포트 → 일지 → 원장 행(마지막)이다. 리포트를 만든 뒤 어떤 예외가 나면 이번 실행이 만든 리포트·일지를 지우고 예외를 다시 올린다(재실행이 write-once에 막히지 않게).
- `--auto`(launchd `daytrade-paper-11` 11:07 KST, `daytrade-paper-14` 14:07 KST 재시도, 2026-10-05 추가): 원장 마지막 날 다음부터
  (원장이 비면 2026-10-05부터) 마감 1시간이 지난 마지막 거래일까지 빠진 세션을 오래된 순서로 실행하고, 처음 실패한 세션에서 멈춘다.
  그날 `reports/history-collection/<YYYYMMDD>.operation.json`이 `COMPLETE`가 아니면 exit 3으로 기다린다. `--accept-incomplete`는
  사람 결정으로 남겨 `--auto`와 함께 쓸 수 없다. 규칙 판단·체결은 `--date` 실행과 같은 코드다.
  exit 4는 사람이 필요하다: 수집기가 다시 받지 않는 지난 날의 영수증이 없음(`STALLED`), 또는 수집이 끝난 데이터가 품질 검사에 실패함(`NEEDS_HUMAN`).
  달력 범위 밖 날짜는 영수증을 보기 전에 exit 2로 거부한다(2026-12-31 전에 달력을 늘린다).
- 자동 실행은 일지 사실 부분을 원래 체크아웃의 `docs/journal/`에 추적되지 않는 파일로 쓴다. 회고를 붙여 PR로 커밋한 뒤 원래 체크아웃을
  병합된 main으로 옮기기 전에, 같은 이름의 추적되지 않는 일지 파일을 `reports/daytrade_paper/journal-autogen/`로 옮긴다(안 옮기면 checkout이 막힌다).

## 7. 정상 주행 점검 판정 (2026-10-05 사용자 결정, 첫 세션 결과를 보기 전 고정)

탐색용 Paper는 우위를 증명하는 단계가 아니라 **"자동 실행이 사고 없이 굴러가는지"** 보는 단계다. 사용자 결정으로
설계 리뷰(`REVIEW_DAYTRADE_SITUATION_LAYER_20261004.md`) §5의 20세션 판정을 **5세션**(2026-10-05~10-09 미국 세션)으로 줄인다.
판정은 5번째 세션의 일지를 쓴 뒤 한 번 한다. 비용 후 원장 기준이며 결과를 본 뒤 숫자를 완화하지 않는다.

| 결과 | 조건 | 다음 |
| --- | --- | --- |
| **소액 실계좌 준비로** | 아래를 모두 만족. ① 5세션 모두 자동 실행으로 기록(누락·거부·원장 끊김 0, `--accept-incomplete` 0) ② 매일 일지 완비 ③ 매일 15:55 전량 청산 ④ 하루 −3% 위반 0 ⑤ 판정·체결 버그 0 ⑥ 진입→청산이 1번 이상 실제로 일어남 ⑦ 누적 ≥ −1.5%, 최대 낙폭 ≤ 5% | 실시간 엔진(`DESIGN_DAYTRADE_REALTIME_EXECUTION_V1.md`) 구현·검증과 Charter §5 조건을 채운 뒤 **USD 500~800 슬라이스**로 같은 규칙 운용. 실제 주문은 별도 사용자 승인 |

| **중단·재설계** | 누적 ≤ −5% · 또는 판정·체결 버그로 원장을 다시 계산해야 하는 사건 2회 이상 | 원인(비용/신호/운영)을 나눠 본 뒤 새 버전 |

- ①의 "자동 실행으로 기록"은 launchd `--auto`가 기록한 것만 센다. 손으로 `--date`를 돌리거나 exit 4를 사람이 풀어야 했던 날은 ① 위반이다.
- Paper는 장 마감 뒤 1분봉으로 계산하므로 손절 체결 지연이 생기지 않는다. 리뷰 §5의 "손절이 조건 성립 2봉 안에 체결"과
  "시스템 결함으로 손절 거리 2배 넘게 밀린 사건"은 **소액 실계좌 단계부터** 센다.
- 5세션의 손익은 표본이 너무 작아 실력의 증거가 아니다. ⑦과 중단선의 손익 숫자는 큰 이상만 거르는 안전 장치다.
  돈은 실계좌 슬라이스의 크기(USD 500~800)와 Charter §5 한도가 지킨다.
- 소액 실계좌 → 시드 전체 증액 기준(리뷰 §5: 40세션 누적 ≥ 0, 낙폭 ≤ 8%, 운영 결함 0)은 소액 실계좌 승인 때 다시 확인해 고정한다.

USD 2,000 계좌로 각 규칙을 따랐을 때, 같은 지수 1배 보유보다 "−35% 중단선보다 먼저 USD 4,000에 닿을 확률"이 높은가?

## 3. 상품 수익 계산(가상 레버리지)

모든 상품은 같은 식으로 계산한다(실제 ETF와 섞어 잇지 않는다). `L`=배수, `s`=0.50%/년(차입 스프레드, assistant 제안).

`r_L = L·r_u + (1−L)·rf − |L−1|·s/252 − ER_L/252`

- 보수 `ER`: 1배 S&P 0.0945%, 1배 나스닥 0.20%, 2·3·−1배 0.95%. 현금 수익은 0이다(Charter §3, 검증된 이자율 없음).
- **보정 점검(전략 계산 전에 먼저, 실패하면 멈춤):** 실제 SPY·QQQ·SSO·UPRO·SH·QLD·TQQQ·PSQ의 총수익(원종가+배당)과
  상장일~2025-07-18 동안 비교한다. 연환산 수익 차이 ≤ 1.5%p, 일수익 상관 ≥ 0.99가 아니면 `CALIBRATION_FAIL`로 끝내고 전략 결과를 만들지 않는다.
- `^SP500TR`과 SPY 총수익+0.0945%/252의 차이도 함께 보고한다(배당 처리 대조).

## 4. 규칙(지수마다 15개, 원문 숫자 고정)

상품: 2배=SSO/QLD, 3배=UPRO/TQQQ, −1배=SH/PSQ(가상). "현금"=0% 수익.

| id | 규칙 |
| --- | --- |
| 1 | 1배 보유(비교 기준) |
| 2 | 2배 보유 |
| 3 / 3i | 지수 종가 > 200일 단순평균이면 2배, 아니면 현금 / −1배 |
| 4 | 3번과 같은 판단, 위면 3배 |
| 5 / 5i | 월말 지수 종가 > 10개월 월말 종가 평균이면 2배, 아니면 현금 / −1배 |
| 6 / 6i | 월말에 직전 12개월 지수 총수익 > 같은 기간 `rf` 누적이면 2배, 아니면 현금 / −1배 |
| 7 | 월말에 노출 `e = min(3, 0.20 / σ)`. `σ`=그 달 일수익 표준편차×√252. 3배 ETF를 `e/3` 비중, 나머지 현금. 월 1회 조정 |
| 8 | 매일 200일선 위면 7번의 `e`(가장 최근 월말 값), 아래면 현금 |
| 9 | 200일선 위 + RSI(2) < 5 → 2배 매수. 지수 종가 > 5일 단순평균이면 매도 → 현금 |
| 10 | 200일선 위 + VIX가 VIX 10일 평균보다 5% 이상 높은 날이 3일 연속 → 2배 매수. RSI(2) > 65면 매도 → 현금 |
| 11 | 월 마지막 거래일 전날 종가에 2배 매수, 다음 달 3번째 거래일 종가에 매도 → 현금 |
| 12 | 10월 마지막 거래일 종가에 2배 매수, 4월 마지막 거래일 종가에 매도 → 현금 |

- RSI는 Wilder 방식, 지수 종가 기준. 이동평균·RSI·σ는 그날 종가까지만 쓴다.
- **실행 시점:** 지표를 쓰는 규칙(3~10)은 t일 종가로 판단하고 **t+1일 종가에 체결**한다(하루 지연, 보수적).
  달력 규칙(11·12)은 날짜가 미리 정해져 있으므로 그날 종가에 체결한다.
  같은 날 종가 체결 결과는 민감도로만 보고하고 판정에 쓰지 않는다.
- **비용:** 매매 금액의 편도 0.15%(수수료 0.10% + 슬리피지 0.05%). stress는 편도 0.25%. 상품을 바꾸면 매도+매수 두 번 낸다.
  7·8번의 월 조정은 바뀐 비중만큼만 낸다. 1배 보유도 첫 매수 비용을 낸다.
- 세금: 판정에 쓰지 않는다. 해외주식 양도세 22%(연 실현이익 중 USD 1,786 초과분, 1,400원/달러 고정)를 적용한 세후 결과를 따로 보고한다.

## 5. 계좌 시뮬레이션과 채점

- 시작점: 1994-02 ~ 2015-07의 매월 첫 거래일 종가(258개). 그날 규칙이 가리키는 노출로 USD 2,000을 투입한다.
- 시작마다 최대 10년을 일별 종가로 따라간다. 결과는 셋 중 하나다.
  - 도달: 계좌 ≥ USD 4,000이 먼저 나옴. 걸린 기간을 기록
  - 중단: 계좌 ≤ 그 시작 이후 최고 계좌 × 0.65가 먼저 나옴(Charter §5 고점 대비 −35%)
  - 미결: 10년 안에 둘 다 없음
- 종가로만 감시하므로 장중 돌파는 놓친다. 이 한계를 결과에 적는다.
- 지표: `P_도달`, `P_중단`, 도달까지 걸린 기간 중앙값, 전체 구간 비용 후 TWR(연환산)·최대 낙폭·거래 수, 인버스 보유일의 수익 기여(3i·5i·6i).

## 6. 채택 판정(Charter v2.1 §2 + 이 사전등록의 시대 점검)

후보 k(지수 i, id 2~12의 14개 × 2 = 28개 비교)는 아래를 모두 만족해야 `PASS`다.

1. `P_도달(k) > P_도달(1배, i)`
2. `P_중단(k) ≤ 0.25`
3. 후보 수 보정: 정상 부트스트랩(Politis–Romano, 평균 블록 250거래일, 1,000회, seed 20261002)으로 1994-02-01~2025-07-18의
   일별 기록(두 지수 수익·`rf`·VIX·그 날의 달력 속성)을 함께 다시 뽑아 같은 채점을 반복한다.
   `p_k = (1 + #{ΔP*_k ≤ 0}) / 1001`, `ΔP = P_도달(k) − P_도달(1배)`. 28개에 Holm 보정을 하고 α = 0.05에서 유지돼야 한다.
   - 지표 준비용 1993-02-01~1994-01-31은 실제 데이터를 그대로 앞에 붙인다. 달력 규칙과 월말 판단은 뽑힌 날의 원래 달력 속성을 쓴다.
   - 시작점은 원래 시작일과 같은 위치(인덱스)를 쓴다.
4. 시대 점검(assistant 제안, 사용자가 정한 "10년씩 3개 시대 점검"의 구체화): 1994-02-01~2004-12-31, 2005-01-03~2014-12-31,
   2015-01-02~2025-07-18 각각에서 새 계좌로 돌린 비용 후 TWR이 1배 보유 이상인 시대가 2개 이상.

- stress 비용에서도 1·2를 만족하는지 함께 보고한다(판정은 기본 비용).
- 통과 후보가 없으면 `NO_PASS`로 기록하고 종결한다. 결과를 본 뒤 숫자를 바꾼 재실행은 새 버전이다.
- 통과해도 Paper나 실주문을 승인하지 않는다(Charter §4).

- 코드: `src/research/stage3_swing/`(데이터 로드·상품 수익·규칙·계좌 채점·부트스트랩·보고) + `scripts/run_stage3_swing.py`.

  (2) 가상 레버리지 — 손으로 계산한 작은 수열과 식이 일치한다(2·3·−1배, 보수·금리·스프레드). (3) 비용 — 상품 교체·월 조정·첫 매수의 비용이 정확히 한 번씩 빠진다.
- 테스트는 합성 데이터만 쓴다. 독립 리뷰 통과 전에는 실제 데이터로 계산을 돌리지 않는다(내려받기는 허용).

## 4. V3A 대비 바뀌는 것

1. **마감 청산 폐지:** 1단 기어(Stage 0)도 장 마감에 청산하지 않는다. `eod_gear1`·`gap_eod` 규칙이 없어진다.
2. **단기봉은 모든 설정에서 15분봉 EMA(9, 21).**
3. **단계(stage):** MFE(1분봉 종가 기준, V3A와 같음)로 단계를 올린다. 단계는 봉 종가에서 정해지고 다음 봉부터 적용된다. 한 봉에서 0 → 2로 바로 오를 수 있다.
   - Stage 0(1단 기어): 하드 스탑(봉 내부 극값, r ≤ −hard_stop) + 15분봉 역교차 청산. 30분 방향 전환만으로는 청산하지 않는다(V3A와 같음, J).
   - Stage 1(MFE ≥ mfe_latch_1): 역교차 무시. 바닥 = 진입가 × (1 + side × lock_1), 봉 내부 극값으로 닿으면 그 가격(갭이면 시가) ∓ 0.02에 청산(`lock_1`).
   - Stage 2(MFE ≥ mfe_latch_2): 바닥을 lock_2로 올린다(`lock_2`).
   - Stage 1·2 공통: 완성된 30분봉의 방향이 보유 방향과 반대이면 다음 봉 시가에 청산(`st_flip`).
4. **스위칭 폐지:** `st_flip` 청산 뒤 반대 방향 즉시 진입이 없다.
5. **사이클당 진입 1회**(30분 방향이 같은 구간).
6. **이격도(anti-chase):** 진입 신호 15분봉의 |종가 − EMA21| ÷ EMA21 ≤ max_ema_dist일 때만 진입.
7. **변동성 필터:** 직전 완성 30분봉 ATR14 ÷ 종가 ≥ vol_min(설정별).

그대로인 것(V3A): 진입 조건(30분 방향, 15분 EMA9/21 정렬, 15분봉 양봉/음봉), 개장 5분 진입 금지, 그날 마지막 봉 진입 금지(J, V3A 유지), 1단 기어 청산 뒤 쿨다운
(15분 + 새 교차), 늦게 완성된 30분봉이 반대면 대기 진입 폐기, 사이징(잔고 95%), 비용(주당 0.02 + 0.005 / 참고 편도 0.10%), 일별 평가, 거래는 진입일 소속.

## 1. 질문과 배경

조건 하나(상태·달력·이벤트)가 맞는 날 **시가에 3배 ETF를 사서 그날 종가에 파는 거래**가, 비용 왕복 0.20%를 뺀 뒤 거래당 평균 순수익 > 0인가.
- 왜 일봉인가(D): 1분봉 연구 둘(진입 v1·추세 전환 v1)은 자료가 약 2.5년뿐이라 우연과 구별되는 최소 우위가 거래당 0.7~2%였고 둘 다 `NO_PASS`였다.
  일봉은 지수별 8~21년의 개발 구간을 주므로 같은 기준에서 0.2~1%까지 내려간다(§6).
- 계좌 시뮬레이션(크기·하루 손실 한도·Charter §2의 USD 2,000 시작점 반복)은 하지 않는다(J: 우위만 분리). 크기 조절은 방법 ④ 사전등록에서 한다.
- 참고 연구(R, 조심해서 요약): Lou, Polk & Skouras 2019 JFE — 주식 수익이 밤사이(전일 종가→시가)와 장중(시가→종가)에 다르게 나뉘며 효과마다 나는 시간대가 다르다.
  Lucca & Moench 2015 JF — 1994년 이후 정례 FOMC 발표 전 약 24시간 동안 미국 주가지수 초과수익이 컸다. Baltussen, Da, Lammers & Martens 2021 JFE — 헤지 수요(딜러 감마)가
  음일 때 장중 모멘텀이 강했다. Ariel 1987, Lakonishok & Smidt 1988 — 월말·월초와 공휴일 전날 수익이 평소보다 높았다는 보고. 이 연구는 그 결과를 **재현하지 않는다**.
  같은 날 시가→종가라는 다른 단위로 바꿔 시험할 뿐이고, 결론은 이 데이터와 이 비용에서만 말한다(J).

| 기준 지수(신호·합성) | 롱 → 매수 | 숏 → 매수 | 실제 ETF 자료 시작(D) |

- **거래 단위 = 세션 하나.** 그날 시가에 사서 그날 종가에 판다(조기폐장일은 13:00 종가). 한 후보 × 한 날에 거래 최대 1번. 후보끼리 서로 영향 없음.
- 기호(D, Yahoo `close` = 분할만 반영한 원종가, `adjclose`는 쓰지 않음): 세션 d, 직전 NYSE 세션 p(d)(`norm/calendar/nyse_sessions.csv`), 지수의 `O_d, H_d, L_d, C_d`.
  지수 장중 수익 `i_d = C_d ÷ O_d − 1`.
- **합성 3배 ETF 수익(판정·p값용, 일일 재조정 반영):** g_d = 배당 보정 갭(§4.1, 총수익 기준).
  롱 `R* = 3 × (1 + g_d) × i_d ÷ (1 + 3 × g_d)`, 숏 `R* = −3 × (1 + g_d) × i_d ÷ (1 − 3 × g_d)`. 이유(J): ETF는 전일 종가에 노출을 3배로 맞추므로 시가 시점 노출은
  밤사이 움직임만큼 이미 변해 있다. 단순 `±3 × i_d`는 **보고만** 한다. R* < −1이면 −1로 자른다(J, 사실상 발생 없음). 아래 `R`은 R*를 뜻한다.
- **순수익(Charter v2.4 §3):** `net = (1 + R) × (1 − c − f) − (1 + c)`, f = SEC fee 0.00206%(매도에만, D). 가격 불변 시 왕복 비용:

| 비용 세트 | c(편도 수수료) | 슬리피지 | 왕복(R=0) | 용도 |
| --- | --- | --- | --- | --- |
| 기본 | 0.10% | 0 | 0.2021% | 판정 |
| 스트레스 | 0.15% | 0 | 0.3021% | 판정(§7.3 ③, §8) |
| 민감도 | 0.05% | 0 | 0.1021% | 보고만 |

- **실제 ETF 대조:** 실제 ETF 자료가 있는 날(DEV 2010년 이후, HOLDOUT 전체)에 같은 비용으로 ETF(`TQQQ/SQQQ/SPXL/SPXS/SOXL/SOXS`, longhist `load_daily`) `C ÷ O − 1`
  순수익을 계산해 후보별 평균·합성과의 상관·평균 차이를 낸다. p값은 언제나 합성 R* 계열로 계산한다. 실제 ETF 평균은 **문턱으로만** 쓴다:
  HOLDOUT 통과에 HOLDOUT 실제 ETF 기본 비용 평균 > 0이 필요하고(§8), ^SOX 후보는 DEV 통과에 DEV 중 2010-03-11 이후 실제 ETF 기본 비용 평균 > 0이 추가로 필요하다(§7.2 ⑤).
  ^SOX를 따로 묶는 이유(D): SOXL·SOXS와 ^SOX의 시가→종가 충실도가 가장 낮다(상관 0.98, QQQ 쌍 0.998). 그 밖의 DEV 실제 ETF 결과는 보고만.
- **알려진 한계(J):** 시가를 신호(갭)와 체결가에 같이 쓴다. 실제로는 개장 직후에야 갭을 알고 사므로 체결가가 다르다. 이 차이는 HOLDOUT 통과 뒤 1분봉 체결 점검(§9)이 잰다.
  ETF 운용보수(연 약 1%, 하루 0.004% 수준)는 넣지 않는다.

## 6. 실행 전 집계 (손익 없음) — 사용자 보고 후 "돌린다 / 멈춘다"

precount는 고정 뒤 구현으로 다시 계산해 `precount.json`에 쓴다: 후보별 DEV n, 반쪽별 n, 정의 안 된 날 수, 제외 사유별 수, HOLDOUT의 달력·이벤트 후보 날짜 수(coverage),
상태 후보의 HOLDOUT 예상 n(= DEV 비율 × HOLDOUT 세션 수, HOLDOUT 가격은 읽지 않음), 그리고 검정력.
sd는 **후보마다 그 후보의 DEV 거래일 R*(롱·숏 각각) 표준편차**(ddof=1, `purpose="performance"`, DEV 날짜만)다. 변동성만 드러내고 후보 평균·손익은 드러내지 않는다.

**미리 계산한 값(D, 2026-10-12 스크립트):** 전체 DEV R* 롱 sd = SPY 3.137%, QQQ 4.933%, ^SOX 4.249%(단순 3배는 3.126·4.913·4.243%). HOLDOUT 세션 2,399(세 지수 모두 coverage 행 2,399).
HOLDOUT 날짜 수: 월 446·화 494·수 491·목 485·금 483, 월말·월초 459, 공휴일 전날 89, 옵션 만기 115, 분기말 38, FOMC 75, FOMC 전날 75, CPI 106, NFP 111. GEX: DEV 1,930일, HOLDOUT 1,645일.

**잡을 수 있는 최소 거래당 평균 순수익(80% 검정력)** `δ = (z_{1−α} + z_{0.8}) × sd_k ÷ √n_k`. DEV는 BH 최악 단계 α = 0.10/156(계수 4.062, 후보별 sd), HOLDOUT은 Holm 첫 단계
α = 0.05/5(계수 3.168, sd는 DEV 전체 R* sd로 대용 J). DEV 값은 롱·숏 중 큰 쪽.

**의미:** 상태·달력 후보는 거래당 약 0.2~1.5%, 이벤트 후보는 1~2% 이상의 우위만 우연과 구별된다. 그보다 작은 우위는 "없음"이 아니라 "확인 불가"로 보고한다.
BH는 진짜 후보가 여럿이면 문턱이 완화되므로 위 DEV 값은 보수적이다. 자동으로 다음 단계로 가지 않는다. 이 집계를 보고 조건·문턱·구간을 바꾸면 v2.

## 7. DEV 검정 (주 묶음 한 번, GEX 묶음 한 번)

### 7.1 통계 (의사코드)

```
for k in candidates (fixed order, prefiltered ones skipped but kept in index):
    x = net(base cost) of candidate k on DEV trade days, sorted by date; n = len(x)
    if n < 2 or sd(x, ddof=1) == 0: p[k] = None
    else:
        rng = numpy.random.default_rng(SEED(variant, k)); m_obs = mean(x)
        for b in 1..B (B = 10_000):
            starts = rng.integers(0, n, size=ceil(n/5))           # 거래 5개 연속 블록, 순환
            xs = concat(x[(s + j) % n] for s in starts for j in 0..4)[:n]
            m_star[b] = mean(xs)
        e = count(m_star - m_obs >= m_obs)
        if e <= 50:                                                # BH 경계 근처 Monte Carlo 오차 줄이기
            redo the loop with B = 200_000 and SEED(variant + 4, k); e, B = new values   # 이 p가 최종
        p[k] = None if var(m_star, ddof=1) == 0 else (1 + e) / (B + 1)   # 한쪽, H0: 평균 ≤ 0
BH (q = 0.10) over the K active candidates:                      # p = None 은 1 로 넣는다
    sort by (p, k) ascending; i* = max{ i : p_(i) <= i × q / K }; reject ranks 1..i* (없으면 0개)
BY (보고만): 같은 절차에서 q 대신 q / Σ_{i=1..K} (1/i)
SEED(variant, k) = 20261012 + 1000 × variant + k
    variant 0 주 DEV 기본 · 1 스트레스 · 2 민감도 0.1021% · 3 실제 ETF 대조 · 4 주 DEV 경계 재계산(B = 200,000)
            10 GEX DEV · 14 GEX DEV 경계 재계산 · 50 주 HOLDOUT · 54 그 경계 재계산 · 60 GEX HOLDOUT · 64 그 경계 재계산
```

구현은 `src/entry_study_v1/stats.py`의 `block_bootstrap_p`(구간 하나로 호출)·`holm_adjust`·`seed_for` 방식을 재사용하고, B 인자와 BH·BY만 새로 더한다.

- 블록 = 그 후보의 날짜순 연속 거래 5개(J, 이전 연구와 같음: 변동성 군집 반영). 반쪽을 넘나들 수 있다(DEV 하나의 연속 구간). 난수는 위 순서로만 뽑는다.
- 스트레스·민감도·실제 ETF·반쪽별·단순 3배 합성은 같은 계산을 **보고만** 한다(BH 묶음 밖, 문턱 쓰임은 §7.2 ③⑤만).

## 8. HOLDOUT (묶음마다 한 번만)

- **부록 PR**(`docs/research/PREREG_DAILY_SAMEDAY_SCREEN_V1_HOLDOUT_ADDENDUM.md`, GEX는 `…_GEX_ADDENDUM.md`): 내용은 **오직** ① 선택된 후보 번호와 정의(§4 그대로),
  ② `config/daily_screen_v1.json`·`precount.json`·`dev_result.json`의 SHA-256, ③ manifest·events yaml SHA-256, ④ 고정 문턱 값. 규칙·문서 본문은 바꿀 수 없다. 병합 커밋 해시가 개봉 조건이다.
- **개봉 조건:** 부록 병합, 사용자 승인(`--i-have-user-approval`), 실행 시 위 SHA 전부 일치. 문턱은 DEV 값 그대로(HOLDOUT에서 다시 계산하지 않음).
- **검정:** 선택 후보마다 HOLDOUT 거래일의 합성 R* 기본 비용 순수익으로 §7.1과 같은 부트스트랩(variant 50/60, 경계 재계산 포함). Holm의 m = **선택된 후보 수 전체**
  (n < 50으로 INCONCLUSIVE가 될 후보도 포함, ≤ M). p를 오름차순(동률은 번호)으로 `adj_(i) = max_{j≤i} min(1, (m − j + 1) × p_(j))`, p = None은 adj 1.
- **`HOLDOUT_PASS`(후보마다 모두 참):** Holm adj p **< 0.05**, n **≥ 50**, 합성 스트레스 비용 평균 **> 0**, **HOLDOUT 실제 ETF(TQQQ/SQQQ/SPXL/SPXS/SOXL/SOXS 시가→종가)
  기본 비용 평균 > 0**. n < 50이면 `HOLDOUT_INCONCLUSIVE`. 같음은 모두 거짓.
- **보고만:** 깨끗한 부분 구간 2016-01-04~2023-04-10(§5.2), 2016~2020 / 2021~2025-07-18 두 부분, 실제 ETF 스트레스 비용·합성과의 상관, 단순 3배 합성, 민감도 비용, 방법 ⑤ 분해.
- 열고 나면 이 연구 묶음에서 HOLDOUT은 사용 완료다. 다시 열어 다른 후보를 시험하지 않는다.

| `HOLDOUT_PASS` | 그 후보를 **1분봉 체결 점검 후보**로: TQQQ/SOXL/SPXL(·인버스) 2021-12~ 1분봉(DB)으로 실제 진입 시각(예: 09:31 시가)·체결 비용 영향을 재는 **별도 사전등록**. 그 자료는 이 HOLDOUT과 겹치므로 선택이 아니라 체결 충실도 확인만 한다. 통과하면 1분봉 intraday 봉인(2026-01-21~07-21)과 일봉 SEAL 개봉은 `OOS_UNLOCK_VERIFICATION_CONTRACT.md` 절차와 다시 사용자 승인으로만 |
| 합성은 통과, 실제 ETF 조건만 실패 | `HOLDOUT_FAIL`(사유 `FIDELITY`)로 기록. 채택 안 함. 합성과 실제 차이는 보고서에서 설명 |

어느 경우에도 실제 주문·Paper 규칙 변경은 별도 계약과 사용자 승인으로만 한다(Charter §4.6).

1. 미래 정보: d의 `C_d, H_d, L_d`와 d 이후 모든 가격·특징 값(지수·VIX·GEX)을 바꿔도 d의 조건 판정이 같다(29 + 3 조건 각각). 세션 달력·이벤트 날짜는 바꾸지 않는다(미리 알려진 값).
   VIX·GEX는 p(d) 값만 쓴다. 문턱은 DEV 자료만으로 계산된다.
2. 봉인·상한: 주 DEV가 2016-01-01 이후, GEX DEV가 2019-01-01 이후, HOLDOUT이 2025-07-19 이후의 `load_daily` 가격을 요청하면 거부(`load_aux` 달력은 허용). 2025-07-21에 닿는 performance 요청은 `OOSLockError`. 부록 없이 holdout 거부.
3. 비용·수익: R = 0에서 0.2021%·0.3021%·0.1021%, 손계산 예시 3개, R < −1 자르기. R* 롱·숏 식 손계산(g ≠ 0, 배당 보정 g 사용), g = 0이면 ±3i와 같음.
4. 후보 목록: config의 후보 수·번호·정의가 이 문서 표(§4.2·§4.3)와 같다. 걸러내기 뒤 K = 156(precount 값과 일치).
5. 달력·이벤트 경계: 셋째 금요일 휴장(예: 성금요일) → 직전 세션, 예정 없던 휴장 전날은 C23 아님, 미해결 달 세션은 이벤트 후보에서 제외, 휴장일 발표 무시, 1994-02-04 이전 FOMC 없음.
6. 특징 경계: `g = 0`(C07~C10 모두 거짓), `|g| = mg` 정확히(큰 갭 쪽), `poc = 0`, VIX 결측(거래 없음, 기록), 배당일 g 보정, ⓐ~ⓔ 제외, 시작일 규칙(0.047619 < 0.05 통과, 0.05 정확히 탈락).
7. 통계: BH·BY·Holm 손계산 예시(동률·None 포함), 고정 시드 부트스트랩 재현, 초과 수 ≤ 50 → B = 200,000·variant + 4로 재계산, 분산 0 → None, n < 2 → None.
8. 데이터 결속: manifest·yaml SHA가 다르면 실행 거부. 결과 파일 덮어쓰기 거부.
9. 실행 순서: `--family gex` precount·dev가 주 `dev_result.json` SHA 없음·불일치, 또는 `NO_PASS` 기록도 병합된 주 부록 커밋도 없을 때 거부.
10. 실제 ETF 문턱: ^SOX 후보의 §7.2 ⑤와 §8 실제 ETF 조건이 손계산 예시대로 판정된다.

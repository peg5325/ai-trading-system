# Feasibility Spike — 자율 자동매매 실증 체크리스트
# (대표 검증 종목 SOXL 포함, 다종목 · 연장시간 전제)

코드 작성 전 반드시 통과해야 하는 검증. 하나라도 실패하면 프로젝트 성립 불가 -> 재설계.
목표: "설계"가 아니라 "이게 실제로 가능한가"를 경험적으로 확인.

## BLOCKER 1 — Toss 미국주식 자동주문 API
프로젝트 성립의 전제. 실패 시 Broker 를 KIS 로 교체 검토.

- [ ] Toss 가 프로그래매틱 API(REST/기타)로 미국주식(SOXL) 주문을 지원하는가?
- [ ] 주문 유형: 시장가 / 지정가 지원 범위?
- [ ] **프리마켓/애프터마켓 주문 지원 여부?** (연장시간 거래 = 필수 요건)
- [ ] 연장시간 지정가 주문 지원? (시장가 미지원 대비)
- [ ] 소수점(fractional) 주문 지원 여부?
- [ ] 주문 상태 조회(체결/부분체결/거부) 상세 제공?
- [ ] 계좌 잔고 / 보유 포지션 / 주문가능금액 조회 API?
- [ ] USD 자동환전 or 원화 주문 처리 방식?
- [ ] 호출 제한(rate limit) / 인증 방식(OAuth 등)?
- [ ] 샌드박스/모의 환경 존재 여부? (Paper Trading 연동용)

**판정:** 자동주문 불가 시 -> MVP Broker 를 KIS 로 변경.

### 결과 (2026-07-06, 읽기 전용 스모크 테스트)
- [x] OAuth2 토큰 발급 OK (client_credentials, Bearer, expires_in≈24h)
- [x] 계좌 조회 OK (accountSeq 확보, BROKERAGE)
- [x] 보유 조회 OK (KRW/USD 평가·손익 반환)
- [x] **미국주식(SOXL) 1분봉 조회 OK** — 심볼="SOXL", currency="USD" 포함
- [ ] 연장/심야 시간대 **주문** 가능 여부 — 미검증 (데이터는 심야에도 나옴, 주문은 별도 실측 필요)
- [ ] 과거 분봉 확보 기간 — 미검증 (BLOCKER 2 로 이어짐)
- 관찰: KST 심야에도 거래량 있는 SOXL 캔들 반환 → 토스 미국주식 24h/연장 데이터 추정, 확인 필요.
- **소결: 인증·조회·미국 분봉은 통과. Toss 를 주문/데이터 브로커로 진행 가능(단, 주문·과거범위·샌드박스는 추가 검증).**

## BLOCKER 2 — 유니버스 과거 분봉 데이터 (Backtest + Screener 전제)
Backtest 불가 시 전략 검증 불가 -> Live 진입 불가. 다종목이므로 종목 단위가 아니라
유니버스(섹터 종목군) 단위로 확보 가능해야 한다.

- [ ] 대상 섹터/유니버스 종목군의 1분봉 or 5분봉 과거 데이터 확보처? (KIS / Polygon)
- [ ] 확보 가능 기간: 최소 1~3년 이상?
- [ ] 다종목 대량 조회 시 호출 제한/비용이 감당 가능한가?
- [ ] split/corporate-action **adjusted** 여부 명시? (레버리지 ETF 역분할 이력)
- [ ] 결측/이상치 빈도 점검 (대표 종목 1개월 샘플 다운로드 후 검사)
- [ ] 종목 리스트(섹터 구성) 조회 소스 — Screener 유니버스 정의용.

**판정:** 유니버스 단위 adjusted 분봉 확보 불가 시 -> 소스/기간/유니버스 재조정.

### 결과 (2026-07-06, Toss 탐침)
- [x] SOXL **1분봉이 최소 3년 전(2023-07)까지** 존재 — 모든 체크포인트 ✓
- [x] 일봉도 3년+ 존재
- [x] 1분봉 한 페이지(200) 연속·무결(갭 없음), 연장/심야 분봉 포함
- [ ] 대량 페이징(3년치 1m ≈ 수백 페이지 × 종목) 시 rate limit 감당 여부 — 미검증
- [ ] adjusted 파라미터(기본 true) 실제 보정 정확성 — 미검증
- **소결: 과거 분봉을 Toss 단일 소스로 조달 가능성 높음. KIS/Polygon 의존 축소 가능(단, 대량조회 한도·adjusted 정확성은 추가 검증).**

## BLOCKER 3 — 참조지표 & 실시간 시세 (다종목)
Screener·Rule Engine·실거래 루프의 전제. 여러 종목을 동시에 감시해야 한다.

- [ ] 다종목 동시 실시간 시세: Toss 실시간성 / 호출제한 / 동시 구독 수 확인 (or KIS WebSocket / Polygon)
- [ ] 참조지표 SOXX / SMH / QQQ 등 섹터 벤치마크 시세 소스 확인
- [ ] VIX 데이터 소스 확인 (Toss/KIS 미지원 시 Polygon)
- [ ] 반도체 개별주(NVDA/AMD/MU/AVGO) 필요 시 소스 확인
- [ ] 실거래 소스 vs 백테스트 소스의 봉 집계/타임스탬프 정합성 (샘플 대조)

**판정:** VIX/참조지표 미확보 시 -> 해당 조건을 룰에서 제거 or Polygon 도입 확정.

### 결과 (2026-07-06, Toss 탐침)
- [x] 섹터 벤치마크 SOXX / SMH / QQQ / SPY 전부 ✓ (USD)
- [x] 반도체 개별주 NVDA / AMD / MU / AVGO 전부 ✓
- [x] **VIX 원본 지수 ✗** (stock-not-found — 지수 미지원) → **VIXY(변동성 ETF) ✓ 로 대체 가능**
- [ ] 다종목 실시간 동시 구독/폴링 한도 — 미검증 (WebSocket 없음, REST 폴링)
- **소결: 참조지표는 Toss 로 조달 가능(VIX 는 VIXY 프록시). 별도 데이터 Provider 불필요 가능성.**

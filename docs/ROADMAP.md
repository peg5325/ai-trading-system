### v1.x 단계 2 기록

- 입력: PRIMARY/VERIFICATION/FREEZE 아티팩트와 정확한 버전·입력 해시.
- 출력: 거래일별 관측 장부, 사후 결과 JSON, JSON에서 생성한 Markdown 보고서.
- 1차 구현 완료: FREEZE Daily Brief 사후 방향성 평가기와 일별/누적 장부 CLI.
  장 마감 전·비FREEZE 입력은 기록하지 않으며, 불완전 일자가 포함된 누적 기간은
  수익률 대신 `INCOMPLETE_PROXY_COVERAGE`를 보고한다. 주문·Paper 체결·승격 판정은 생성하지 않는다.
- 시작일: 구현·리뷰 완료 후 첫 미래 거래일을 실행 전에 기록한다.
- 시작 전에 하나의 전략 템플릿과 모의 체결 규칙·위험 제어를 고정한다.
  같은 10거래일에 Shadow와 Paper를 함께 수행하며 별도 60거래일을 추가하지 않는다.
- 2026-09-21 데이터는 회귀 사례로만 사용한다. 과거를 새 전향적 표본으로 취급하지 않는다.
- 관찰용 고정 비교: FREEZE 최대 3종목 동일 비중, 정규장 첫 봉 시가→마지막 봉 종가.
  LONG/SHORT 부호와 비용을 반영하되 실제 체결·차입 가능성을 입증한 매매 성과로 부르지 않는다.
- 시가/종가 경로는 방향성 proxy다. 미승인 전략에 따른 실제 시스템 결정 NO_TRADE와
  가상 watchlist 결과를 각각 보존한다. 계좌 수익률은 실제 결정 경로만 사용한다.
- 통합 평가의 경제성은 고정 전략의 모의 계좌 결과로 판정한다. 위 방향성 proxy를
  모의 체결 수익으로 대신하지 않는다. 모의 전용 승인과 실거래 승인은 분리한다.
- MFE/MAE·순위 품질·단계 간 후보 교체·SPY 동시간대 비교는 진단 지표로 별도 보고한다.
  장중 SPY 시가→종가 비교를 연간 buy-and-hold 벤치마크로 바꾸지 않는다.
- 결과는 순수익률·초과수익·순손익·최대낙폭 순으로 제시한다. 승률과 수익일 비율은
  보조 지표이며 낮다는 이유만으로 탈락시키지 않는다. 상세 정책은 Charter를 따른다.
- 정규장 종료·조기폐장·DST, 중복/누락/미완성 봉을 검증한다.
  결측일을 제거하거나 수익률 0으로 채우지 않고 유효/예정 세션 수를 병기한다.
- 예정 세션 중 완전 관측 ≥95%를 운영 목표로 사용한다. 누락은 100% 사유 기록.
  95% 통과가 편향 없는 성과를 보장하지 않는다. 비무작위 결측은 별도 검토한다.
- 보고서·자동화 요약은 동일 결과 JSON에서 생성하여 후보 유무 불일치를 방지한다.
- 이 단계에서 실제 자동화 예약 변경·주문·OOS 개봉은 별도 구현 작업으로 다룬다.

## 도구 선택과 범위

- 현재 수집/검증 기반을 유지한다. LLM 판단 도구(TradingAgents 등)는 과거 검증이 불가능해 매매 판단에 쓰지 않는다(Charter §4.1).
- skfolio는 여러 자산 비중이 필요할 때 검토한다. Kronos는 독립 테스트에서 무작위 수준이라는 보고가 있어 보류한다.
- NautilusTrader는 실행 기반의 구체적인 한계와 Toss 연동 비용 확인 후 검토한다.
- 기존 1개월 연구 계획은 종료 기록으로 보존한다. 이 문서가 현재 목표의 진행 정본이다.
- 구현마다 이슈/브랜치/PR과 검증 근거를 Status에 기록한다. 이번 문서 작성은
  전체 로드맵의 실행·병합·배포 승인으로 해석하지 않는다.

## 갱신 규칙

단계 완료, 정책 변경, 차단 발견 시 이 문서와 Status를 함께 갱신한다.
Charter의 정책을 중복 복사하지 않고 링크로 참조한다. 과거 증거는 덮어쓰지 않는다.
